## 📚 Anotações de Estudo: Comandos Básicos do Git

Abaixo estão registrados os principais comandos praticados pela equipe durante a execução deste projeto:

- `git clone <url>`: Clona o repositório remoto para a máquina local.
- `git config --global user.name` / `user.email`: Configura a identidade do autor dos commits.
- `git pull origin main`: Atualiza o repositório local com as alterações do repositório remoto.
- `git add .`: Prepara as alterações locais para o commit.
- `git commit -m "mensagem"`: Registra as alterações no histórico com uma descrição clara.
- `git push origin main`: Envia as alterações locais para o GitHub.
- `git log --oneline`: Exibe o histórico simplificado de commits do projeto.

## 💡 Boas Práticas de Commit Aprendidas
- Escrever mensagens claras e no imperativo ou indicativo curto.
- Fazer commits pequenos e frequentes.
- Sempre atualizar o repositório local (`git pull`) antes de enviar alterações.
